# TLP для Android (Flet)

Порт програмного комплексу TLP з Tkinter на Flet. Word-документи формуються власним
генератором (без python-docx/lxml), тому збірка під Android проста.

## Збірка APK у хмарі (найпростіше)
1. Створіть репозиторій на GitHub і завантажте в нього вміст цієї папки.
2. Вкладка **Actions → Build APK → Run workflow**.
3. Через 10–20 хв. завантажте артефакт **TLP-apk** — це файл `.apk`.

## Збірка локально (Linux або WSL2 в Windows)
```
pip install "flet==0.28.3"
flet build apk
```
Потрібні Java 17 та Flutter (Flet запропонує встановити сам). Результат: `build/apk/`.

## Запуск на ПК для перевірки
```
pip install "flet==0.28.3"
python src/main.py
```

## Структура
- `src/main.py` — вхід
- `src/tlp/spec.py` — опис усіх форм Кроків 1–8 (тексти-зразки, поля, таблиці)
- `src/tlp/ui.py` — інтерфейс Flet
- `src/tlp/export.py`, `docx_min.py`, `timeline.py` — формування TLP.docx та Timeline (A3)
- `tests/` — тести

## Що змінено порівняно з Tkinter-версією
Виправлено друкарські помилки у зразках; крок 1 — одна прокручувана форма; прибрано
Windows-специфіку (os.startfile, шляхи Desktop/OneDrive); ASCII-схему МСОО не перенесено;
TLP_Gui/TLP_Steps/TLP_Chart/step3.py не використовувались і не включені.
Дані зберігаються у приватній папці застосунку; кнопки на головному екрані зберігають .docx.

## Не перевірено
Збірку APK і роботу інтерфейсу на справжньому Flet я не міг перевірити (у моєму середовищі
заблоковано PyPI). Логіка, експорт у Word (перевірено в LibreOffice) і побудова форм
протестовані. Найменш певне місце — збереження файлу через системне вікно на Android.
